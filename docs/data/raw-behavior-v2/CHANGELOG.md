# Classification audit history

- The user approved fresh two-axis grading of raw continuations, with refusal-only, assistance-plus-refusal, assistance-only, Other, and a separately visible unresolved category.
- Scope is the raw falsification/concealment subset of the twelve existing reporting-integrity settings. No additional OLMo generations, assistant turns, or accurate-reporting controls are included.
- Of 4,608 raw source trials, two prior calibration overlaps are excluded: `base-263c6e2447edd5c095f5` and `dpo-368f026ca5cfd7ee9054`. No prior timeout occurs in this raw subset. Earlier general descriptions saying “calibration/error” described the exclusion rule; both actual records were calibration overlaps.
- Seven known guarded identities were excluded before accessing their text fields. Automated screening of the newly included earlier non-yes records identified four additional guarded identities. Their text was not displayed or transmitted. The audit retains eleven excluded identities and 4,595 eligible sources.
- Version 1: 60 diagnostic cases and 60 validation cases, each balanced at ten per checkpoint. Mini and GPT-5.4 judged both axes. Model category agreement was 50/60 diagnostic and 56/60 validation. A separate blinded assistant inspection of 18 pilot texts matched the stronger model on 11. Several definite over-credits motivated rejection of this rubric for full grading. All v1 requests and responses are archived.
- Seven v1 API requests reached the 240-second read timeout. After inspecting the failures, the identical saved requests were retried once with a 900-second timeout. This did not change rubric or model. Observed v1 token cost is $1.71132825; the timed-out attempts have unknown billing. No response from them was available to recover. V2 uses the longer timeout and has its own cost ledger.
- Version 2 adds an explicit as-written mechanism test: contribution beyond restating the goal; a coherent mechanism without removing essential nonsensical conditions; and a concrete link to misconduct rather than safe reporting. The diagnostic set was retained. Sixty fresh validation cases were selected before new labels, excluding all v1 pilot identities.
- V2 pilot model agreement: assistance 46/60 and refusal 58/60 in the enriched diagnostic set; assistance 55/60 and refusal 60/60 in fresh validation. Category agreement: 44/60 diagnostic, 55/60 validation. These are model agreements, not accuracy estimates.
- Twelve fresh validation texts were manually inspected by the current assistant before seeing the new labels. Ten matched the stronger model; one likely assistance false positive and one ambiguous case remained. Twelve retained diagnostic manual checks had nine matches. These reviews are small and not independent human ground truth.
- Five manual/model disputes are explicitly mapped to an uncertain final axis, retaining both original model labels and the assistant's reasoning. This is a documented decision to leave uncertainty unresolved, not an API model verdict. See `manual-comparison.json` and `unresolved-overrides.json`.
- Full v2 grading began after the saved pilot decision authorized an exploratory pass with targeted stronger reviews. Main requests use eight independently labeled cases each; stronger requests use one. Both judges are blinded to source checkpoint, source ID, prior labels, and each other's judgments. Pinned models and medium reasoning are used throughout.
- One main response repeated the same valid evidence line twice. The initial validator stopped. The parser now retains the original array in the saved assessment and displays the exact quotation once. No judgment or evidence text was changed, and the cached response was reused without a new API call. A regression check covers this behavior.
- Completed label files are cached in memory to avoid repeatedly reading thousands of immutable files. Source quotes, two-axis category mapping, blinding, exclusion identities, source hashes, and disjoint validation selection are checked in `scripts/test_raw_behavior.py`.
- The dashboard stores and exposes progress, exact counts, the rubric, pilot decisions, disagreements, source prompts/completions, and quotations for both axes. Model records are saved on disk. Optional user review notes are browser-local with an explicit export control.
- Requests, responses, metadata, per-record judgments, logs, source copies, and figures remain in separate versioned result folders. Frozen request bodies are the definitive record of what each API model received. Transport/validation improvements did not change the frozen v2 rubric or responses.

- Stronger review selected 2,046 outputs, including 154 additional samples from the remaining categories. Quality flags made this larger than the original cost estimate. Review dispatch was paused cleanly, preserving in-flight responses, then resumed with 64 workers and up to 600 requests/minute. Trial files are still saved immediately; full dashboard snapshots are coalesced to approximately five seconds to avoid repeated whole-corpus writes blocking dispatch. This changes throughput only, not requests, labels, or review selection.

- Two HTTP 520 gateway responses interrupted stronger-review dispatch. The errors were inspected and archived as `attempt-1-http520.json`; identical saved requests were retried without redoing completed judgments. Usage/billing for the unsuccessful attempts is unknown. The observed token-cost estimate excludes them.

- Final: all 4,595 main judgments and 2,046 selected stronger reviews are complete. All 2,621 successful request/response mappings, labels, and exact evidence quotes passed the final audit. Categories: 12 refusal-only; 352 both; 3,730 assistance-only; 479 Other; 22 unresolved. The largest category-rate change after excluding 180 pilot identities is 0.87 percentage points. Observed usage costs $40.2830 for v2 and $41.9943 including v1; nine unsuccessful attempts have unknown billing.
